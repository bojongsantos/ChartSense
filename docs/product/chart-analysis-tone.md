# Chart Analysis Tone Guide

Panduan ini hanya berlaku untuk output analisis pada halaman Chart Analysis.

## Tone

Gunakan bahasa formal seperti research note broker profesional. Analisis harus
cepat dibaca, padat, dan tanpa basa-basi.

## Aturan bahasa

| Hindari | Gunakan |
|---|---|
| Nah, ada... | Saat ini terdapat... |
| Jadi rencananya gini | Rencana entry |
| kripto bisa gerak cepat | pergerakan kripto dapat terjadi cepat |
| soalnya | karena |
| cuma kalau | hanya jika |
| tandanya | menunjukkan |
| sepi-sepi saja | terbatas |
| saja | hilangkan jika tidak diperlukan |

- Maksimal 15 kata per kalimat.
- Satu bullet memuat satu ide.
- Tampilkan angka secara langsung tanpa preamble.
- Gunakan bold hanya untuk entry, stop loss, target, dan persentase.

## Nama section

- Ringkasan Setup
- Market Structure
- Key Level
- Momentum
- Risk Management

## Anti-pattern

- Klaim marketing berlebihan.
- Bahasa emosional.
- Basa-basi.
- Duplikasi antara narasi dan data terstruktur.
