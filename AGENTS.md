# ChartSense Tone & Style Guide

## Konteks
Panduan ini KHUSUS untuk output AI Analysis di halaman Chart Analysis
ChartSense. Bukan untuk konten marketing, blog, atau media sosial.

## Tone Default
Formal, seperti research note broker profesional. Target pembaca: trader
yang ingin analisa cepat, padat, dan tanpa basa-basi.

**Bukan** gaya colloquial ("Nah", "gini", "cepet") — itu untuk konten
publik / marketing di produk lain.

## Aturan Bahasa

### Pilih Kata
| Hindari | Gunakan |
|---|---|
| Nah, ada... | Saat ini terdapat... |
| Jadi rencananya gini | Rencana entry |
| kripto bisa gerak cepet | pergerakan kripto dapat terjadi cepat |
| soalnya | karena |
| cuma kalau | hanya jika |
| tandanya | menunjukkan |
| sepi-sepi aja | terbatas |
| aja | (hilangkan) |

### Struktur Kalimat
- Maksimal 15 kata per kalimat
- Satu bullet = satu ide
- Data angka langsung tanpa preamble ("Entry 63155.2" bukan "Rencananya
  masuk di harga 63155.2")

### Nama Section
Nama teknis dalam bahasa Inggris, penjelasan dalam Indonesia formal:
- Ringkasan Setup
- Market Structure
- Key Level
- Momentum
- Risk Management

### Bold
Hanya untuk angka kunci: harga entry, stop loss, target, persentase.

## Anti-Pattern
- Bahasa marketing berlebihan ("keyakinan tinggi", "peluang emas")
- Emosi ("sangat menarik", "wajib dicoba")
- Basa-basi ("Perlu diketahui bahwa...")
- Duplikasi info (narasi + data terstruktur di baris berbeda)
